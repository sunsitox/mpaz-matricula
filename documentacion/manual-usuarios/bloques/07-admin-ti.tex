\section{Administración TI}

Administración TI maneja las cuentas y la configuración del año escolar. No
tiene acceso al expediente de los estudiantes.

\subsection{Cuentas de funcionarios}

\captura{13-funcionarios}{0.95}{Administración de funcionarios: crear, editar, desactivar o restablecer contraseña.}

\begin{itemize}[leftmargin=*,itemsep=0.2em]
\item \textbf{Crear funcionario}: nombre, correo institucional y rol. El
  sistema entrega una clave temporal que debe cambiarse en el primer ingreso.
\item \textbf{Editar}: corrige el nombre o los roles vigentes.
\item \textbf{Desactivar}: deja la cuenta sin acceso; no se borra.
\item \textbf{Cerrar rol}: termina un rol con fecha y conserva el historial.
\item \textbf{Restablecer contraseña}: genera una clave temporal de un solo
  uso y cierra las sesiones abiertas de esa persona.
\item \textbf{Desbloquear}: libera una cuenta bloqueada por intentos fallidos.
\end{itemize}

\subsection{Año escolar}

\captura{14-anio-escolar}{0.95}{Configuración del año escolar con matrícula activa y su periodo.}

El año de matrícula \textbf{no se calcula con el calendario}: se configura. El
portal trabaja siempre con el año marcado como activo y su periodo de
matrícula.

\begin{enumerate}[leftmargin=*,itemsep=0.2em]
\item Entre a \textbf{Configuración}.
\item Agregue el año nuevo con su fecha de inicio y de término.
\item Active el año nuevo cuando el colegio abra el proceso.
\end{enumerate}
